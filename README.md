# DirectoryX

**DirectoryX** is a C# console-based file and directory management utility built using the `System.IO` namespace.

The project is currently in **v1.0** and is being developed to build practical experience with file system operations, directory management, error handling, and C# application structure.

## Current Features

DirectoryX currently provides the following options:

```text
Welcome to DirectoryX v1.0, select from the following options below.

1. List Files
2. List Directories
3. Create Folder
4. Create File
5. Delete Folder
6. Delete File
7. Exit
```

### File Operations

* List files
* Create files
* Delete files

### Directory Operations

* List directories
* Create folders
* Delete folders
